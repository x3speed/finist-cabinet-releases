# FINIST — личный кабинет для WordPress

Публичные выпуски плагина для f-inox.ru. ZIP содержит только код, стили и библиотеки плагина. Каталог цен, исходные прайсы, демоверсия и клиентские документы сюда не загружаются.

## Скачать

Откройте [последний стабильный выпуск](https://github.com/x3speed/finist-cabinet-releases/releases/latest) и скачайте `finist-cabinet-<версия>.zip` из Assets. Архивы `Source code` для установки не предназначены.

`finist-cabinet-update.json` — служебный манифест с версией, требованиями и SHA256 ZIP. Его читает плагин; загружать этот файл как каталог не нужно.

## Обновления

Начиная с 1.5.0 плагин проверяет стабильные GitHub Releases через штатный механизм WordPress. Токен не требуется. Первый переход на 1.5.0 выполняется вручную. При разрешённых обновлениях автообновление FINIST включается один раз при входе администратора в панель; последующее отключение в разделе «Плагины» сохраняется.

Статус: **Кабинет FINIST → Обновления → Проверить сейчас**. Фоновая установка зависит от прав WordPress, файловой системы и работающего cron. Плагин не снимает ограничения хостинга.

Приватный `catalog-package.json` предоставляется отдельно и импортируется вручную: **Кабинет FINIST → Каталог**. Выпуск с новым адаптером расчёта требует совместного ручного обновления плагина и JSON; автоматическая установка такого выпуска блокируется. Сохранённые спецификации и персональные скидки не пересчитываются при обновлении.

## Требования

WordPress 6.5+, PHP 8.1+ с mbstring, dom и gd; HTTPS, MySQL/MariaDB с InnoDB. Для импорта полного каталога требуется memory_limit не меньше 1024M, upload_max_filesize 64M и post_max_size 80M. Библиотеки PDF входят в ZIP.
